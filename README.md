# ⚔️ NEON QUEST

بازی RPG زندگی واقعی با تم Cyberpunk + Fantasy

## ساختار پروژه

```
neonquest/
├── index.html       ← فایل اصلی
├── css/
│   └── style.css    ← همه استایل‌ها
├── js/
│   ├── data.js      ← داده‌ها (کلاس‌ها، آیتم‌ها، پت‌ها)
│   └── engine.js    ← منطق بازی + رندر
└── README.md
```

> Three.js از CDN لود میشه (نیاز به اینترنت داره)
